# Phase 8｜活動卡包與新鮮感管理

本階段完成 PRD v1.0 中「防膩與長期新鮮感機制」的第一版。

## 已完成

1. 新增活動與卡包資料層：`lib/data/events.ts`
2. 新增活動與卡包 server actions：`lib/actions/events.ts`
3. 新增後台頁面：`/parent/events`
4. 後台 Dashboard 顯示目前活動、啟用卡包數、剩餘庫存
5. 小孩端首頁顯示目前活動提示與今日獎勵卡包
6. 未設定 Supabase 時保留 demo fallback

## 新增頁面

```text
/parent/events
```

可管理：

- 新增活動
- 新增卡包
- 指定活動卡包
- 設定開始日期與結束日期
- 查看卡包內卡片數與剩餘庫存

## 小孩端首頁顯示

小孩端首頁會優先讀取啟用中的活動：

- 活動名稱
- 首頁提示文字
- 今日獎勵卡包

若沒有活動，則顯示預設提示。

## Supabase 對應資料表

使用既有資料表：

- `events`
- `reward_packs`
- `reward_pack_items`

## 使用目的

這一階段的重點不是增加複雜功能，而是讓家長可以持續更新新鮮感：

- 小車週
- 狗狗週
- 恐龍週
- 生日限定卡
- 假日限定卡包
- 弱點挑戰卡包

讓孩子每天不是只做一樣的題目，而是有新的獎勵期待。
