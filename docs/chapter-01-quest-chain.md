# Chapter 1 任務鏈設計文件

## 主線目標

第一章的核心任務鏈為：**完成冒險地圖 10 個節點，收集星星朋友，打開今日卡包**。

- 單一故事目標：協助小光獸完成 10 關冒險，打敗 3 個 Boss，蒐集卡片。
- 預估完成時間：3–5 分鐘。
- 出口條件：冒險地圖 10 節點全數完成，或至少完成 Boss 關卡。

## 第一章完整流程

```
首頁（今天出發）
    │
    ▼
冒險地圖（/adventure）— 10 節點，3 個 Boss 節點
    │
    ├─► 前往第 N 關  ──► 練習頁（/practice）— 每日題目（注音 + 英文）
    │       │
    │       ▼
    │   完成練習 ──► 返回地圖，節點標記完成
    │
    ├─► Boss 關卡 ──► Boss 戰鬥頁（/boss）— 3 題問答，HP/能量機制
    │       │
    │       ▼
    │   打敗 Boss ──► 獎勵頁（/reward）— 開啟今日卡包
    │
    └─► 10 關全完成 ──► 查看收納包（/collection）
```

## 場景定義

### 1. 首頁（/）
- **功能**：今日冒險入口、進度概覽、星星圖鑑快速連結。
- **故事語境**：小光獸今天要出發找星星朋友，完成 5 個小任務。
- **互動**：按下「開始冒險」進入冒險地圖。

### 2. 冒險地圖（/adventure）
- **功能**：10 節點路線圖，顯示目前關卡、已完成/未解鎖狀態。
- **Boss 節點**：第 3、6、9 關為 Boss 節點（0-based index 2、5、8）。
- **互動**：當前節點可點「前往第 N 關」或「挑戰 Boss」。

### 3. 練習場（/practice）
- **功能**：每日題目生成與作答（choice + tracing 模式）。
- **內容**：注音（ㄅ、ㄇ…）與英文大寫字母（A…）混合題組。
- **回饋**：完成後回傳星星、星光、寵物經驗至冒險地圖。

### 4. Boss 戰鬥（/boss）
- **功能**：3 題問答戰鬥，HP/能量機制，限時節奏。
- **獎勵**：完成後解鎖下一組節點，並可開啟卡包。

### 5. 今日卡包（/reward）
- **功能**：翻牌動畫，每日限定次數，角色卡片收集。
- **互動**：翻開後可选择「儲存到收納包」。

### 6. 收納包（/collection）
- **功能**：已收藏卡片一覽，顯示星星朋友完成度。
- **家長功能**：右下角可進入家長後台。

|------|------|------|

## 擴展區域規劃

- **數學森林（Math Forest）**：目前存在於 feature/level-gameplay-math-language 分支，尚未合併至 main。規劃為注音/英文練習的主題化包裝，未來可作為冒險地圖的區域外觀。
- **語言村（Language Village）**：尚未實作。規劃為配對或造句互動，作為第二個主題区域。

## 設計限制

- **單一故事目標驅動**：第一章不允許多條主線並行，避免兒童選擇困難。
- **3–5 分鐘可玩**：10 節點 + 3 Boss = 符合幼兒注意力長度。
- **無 dead-end**：任何節點完成後必須返回地圖或自動導向下一步。
