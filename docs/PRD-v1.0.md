# PRD v1.0｜兒童英文＋注音練習 PWA

## 專案名稱：星見練習本

## 版本：v1.0

## 產品型態：手機優先 PWA 網頁 App

## 目標：零額外月費建置、家庭自用、不上架、不盈利

---

# 01｜產品背景

本產品為一套給幼兒使用的英文與注音練習系統，主要使用場景為手機或平板。家長可在後台管理學習素材、記憶詞、題型、卡片、卡包與獎勵條件；小孩端則以簡單、明瞭、圖像化、大按鈕的方式進行每日練習。

本產品核心目的不是商業化，而是建立一套可長期使用、可持續更新內容、能讓孩子願意每天打開練習的家庭學習系統。

---

# 02｜產品目標

1. 讓小孩每天願意練習英文與注音。
2. 透過記憶詞、圖片、聲音與多題型變化，幫助孩子建立記憶。
3. 系統自動記錄孩子的學習進程，找出容易忘、常答錯的項目。
4. 系統能自動安排新題、複習題、弱點題。
5. 完成練習後可獲得隨機收藏卡，提升持續使用意願。
6. 家長可不斷新增卡片、卡包、系列與活動，避免孩子太快玩膩。
7. 整套系統以免費工具建置，不產生固定月費。

---

# 03｜產品定位

手機版兒童英文＋注音練習 PWA，結合自動出題、弱點複習、通關抽卡與家長後台卡片管理。

產品包含：

1. 學習練習系統
2. 弱點複習系統
3. 家長內容管理系統
4. 卡片收藏獎勵系統
5. 手機 PWA 家用系統

# 04｜使用者角色

## 4.1 小孩端使用者

主要使用者為幼稚園階段兒童。

需求特徵：

1. 尚未具備大量閱讀能力。
2. 操作需要簡單、直覺、大按鈕。
3. 每次練習時間不可過長。
4. 需要聲音、圖片、動畫與即時回饋。
5. 需要獎勵與收藏動機。
6. 不應看到複雜數據、設定、報表或後台資訊。

## 4.2 家長端使用者

需求特徵：

1. 可新增英文與注音學習項目。
2. 可設定多個記憶詞。
3. 可上傳圖片與音檔。
4. 可新增卡片、系列、分類與卡包。
5. 可設定抽卡條件與活動卡包。
6. 可查看孩子學習進度與弱點。
7. 可持續更新獎勵內容，避免孩子玩膩。

# 07｜小孩端功能規格

## 7.1 小孩首頁

首頁需極簡，顯示孩子名字、今日任務狀態、今日可獲得的卡包、收納包入口與開始練習按鈕。

範例文字：

- 星見今天要練習囉！
- 完成今天練習，可以打開小車卡包！
- 今天有新卡登場！

## 7.2 今日任務頁

小孩端只顯示簡化資訊：今天 10 題、完成就可以抽卡、今天有新朋友與需要複習的朋友。

不可顯示新題比例、複習題比例、弱點題比例與熟練度計算規則。

## 7.3 題目頁

題目頁採一題一頁。

基本版面：

1. 上方：進度條與星星
2. 中間：題目主視覺
3. 下方：大選項或描寫區
4. 最底部：重聽、重畫、下一題等按鈕

所有題目需支援語音播放。

## 7.4 題型

### 認識題

範例：ㄅ 是爸爸的 ㄅ、A 是 Apple 的 A。

### 選擇題

範例：爸爸的 ㄅ 在哪裡？選項：ㄅ、ㄆ、ㄇ、ㄈ。

### 聽音題

播放記憶詞或發音，孩子選擇正確符號或字母。

### 描寫題

顯示大字母或注音符號、淡色底稿，讓孩子手指描寫。第一版只需簡單判斷是否有描寫與完成度，不做高精度 AI 辨識。

### 回想題

範例：爸爸的第一個聲音是什麼？Apple 的第一個字母是什麼？

### 分類題

範例：找出 ㄅ 的朋友。選項可包含爸爸、拜拜、媽媽、抱抱。

## 7.5 完成頁與抽卡頁

完成今日任務後顯示鼓勵文字，並引導打開卡包。抽卡頁需有卡包或禮物盒動畫、翻卡、顯示獲得卡片、顯示是否新卡、放入收納包。

## 7.6 收納包

收納包以圖鑑方式呈現，顯示全部系列、各系列進度、已獲得卡片、未獲得卡片剪影與卡片放大查看。

# 08｜小孩端 UI 原則

1. 手機優先，以 375px、390px、414px、430px 直式寬度為主。
2. 一頁只做一件事。
3. 一次只顯示一題。
4. 按鈕要大，字體要大，圖片要清楚。
5. 不使用多層選單。
6. 不要求精準點擊。
7. 錯誤提示不能造成挫折。
8. 答對要有明確正向回饋。
9. 所有題目盡量可播放語音。

建議尺寸：

1. 主標：28px 以上
2. 題目：24px 以上
3. 選項：22px 以上
4. 按鈕：20px 以上
5. 主要按鈕高度：64px 至 80px
6. 選項卡片高度：80px 至 110px
7. 描寫區至少佔畫面 45% 以上

視覺方向：奶油色背景、柔和藍、柔和黃、柔和綠、大圓角、大卡片、輕動畫、星星、彩帶、禮物盒。

答對回饋：太棒了、你找到爸爸的 ㄅ、答對了、星星送給你。

答錯回饋：再試一次、聽聽看、差一點點、爸爸的 ㄅ 長這樣喔。

# 09｜家長後台功能規格

## 9.1 後台登入

家長後台需登入後才可進入。第一版可使用 Supabase Auth 或簡單密碼保護。

## 9.2 Dashboard

顯示今日是否完成練習、今日完成題數、今日正確率、今日是否已抽卡、目前弱點項目數、已掌握項目數、卡包剩餘數、最近抽到的卡片、本週連續練習天數。

## 9.3 學習項目管理

管理英文字母大寫、英文字母小寫、英文單字、注音聲母、注音韻母、注音結合韻、注音聲調、注音拼音組合。

每個項目包含類型、內容、顯示文字、發音音檔、描寫底稿、筆順資料、難度、是否啟用。

## 9.4 多記憶詞管理

每個注音或字母可設定多個記憶詞。

範例：

- ㄅ：爸爸、拜拜、不見、抱抱、寶寶、杯子
- ㄇ：媽媽、蜜蜂、妹妹、麵包、貓咪
- A：Apple、Ant、Airplane、Alligator
- B：Ball、Banana、Baby、Bus、Book

每個記憶詞包含記憶詞、記憶句、圖片、音檔、是否主要記憶詞、難度、出題階段、是否啟用。

## 9.5 題型模板管理

系統需以模板自動生成題目，而不是要求家長每題手動輸入。

題型模板包含認識題、選擇題、聽音題、描寫題、回想題、分類題。

## 9.6 手動題目管理

雖然主要採自動生成，仍需支援手動指定題目。可設定題目文字、題目類型、正確答案、選項、指定孩子、指定日期、是否必出、是否啟用。

## 9.7 每日任務設定

家長可設定每日總題數、新題比例、複習題比例、弱點題比例、完成後是否可抽卡、每日最多抽卡次數、是否啟用連續天數獎勵、是否啟用弱點挑戰加抽。

預設：每日總題數 10 題，新題 30%，複習題 40%，弱點題 30%。若弱點過多，系統可自動提高弱點題比例。

## 9.8 學習進度頁與弱點分析

顯示每個學習項目的熟練度、練習次數、答對次數、答錯次數、正確率、連續答對、連續答錯、最近練習時間、最近答錯時間、下次複習時間、是否弱點。

弱點分析顯示最常錯的注音、最常錯的英文字母、最容易忘的項目、最近退步的項目、建議明天加強的項目。

# 10｜自動出題系統

## 10.1 出題來源與優先順序

每日題目來源包含家長指定題、弱點項目、到期複習項目、新學習項目。

優先順序：家長指定題、弱點題、到期複習題、新題。

## 10.2 題目生成方式

每題生成流程：

1. 選擇 learning_item
2. 選擇 memory_hook
3. 選擇 question_template
4. 套入題目文字
5. 產生選項
6. 產生正確答案
7. 存入 generated_questions

## 10.3 同一符號多講法重複出現

系統需允許同一注音或字母重複出現，但講法不同。

範例：

1. ㄅ 是爸爸的 ㄅ
2. 拜拜也有 ㄅ
3. 不見的第一個聲音是 ㄅ
4. 抱抱也有 ㄅ
5. 找出 ㄅ 的朋友

## 10.4 熟練度與記憶詞使用邏輯

低熟練度：優先使用主要記憶詞，題型以認識題、選擇題為主。

中熟練度：加入延伸記憶詞，題型加入聽音題與描寫題。

高熟練度：混合多個記憶詞，加入干擾選項，題型加入回想題與分類題。

# 11｜學習進程與弱點複習

## 11.1 熟練度等級

0：未學習  
1：初學  
2：練習中  
3：基本熟悉  
4：熟練  
5：已掌握

## 11.2 每次作答記錄

每一題作答需記錄孩子、學習項目、記憶詞、題型、是否答對、分數、花費時間、錯誤類型、作答時間。

## 11.3 答對與答錯更新規則

答對後：答對次數 +1、連續答對 +1、連續答錯歸 0、熟練度可能上升、下次複習時間延後。

答錯後：答錯次數 +1、連續答錯 +1、連續答對歸 0、熟練度可能下降、標記為弱點、下次複習時間提前。

## 11.4 弱點判斷條件

符合任一條件即進入弱點：

1. 最近 3 次有 2 次答錯
2. 正確率低於 70%
3. 連續答錯 2 次
4. 隔幾天複習後又答錯
5. 描寫完成度低於 70%
6. 聽音辨識常選錯

## 11.5 複習間隔

熟練度 0 至 1：每天複習  
熟練度 2：2 天後複習  
熟練度 3：4 天後複習  
熟練度 4：7 天後複習  
熟練度 5：14 天後複習

# 12｜卡片收藏獎勵系統

## 12.1 核心目的

卡片系統的主要目的不是單純遊戲化，而是維持孩子長期練習意願。

核心邏輯：孩子每天為了新卡回來，但回來的過程中完成學習。

## 12.2 卡片系列與分類

家長可新增系列與分類。範例：Tomica 小車系列、布麗狗系列、Pikmin 系列、恐龍系列、動物朋友系列、爸爸特製系列。

## 12.3 卡片上傳與套版

家長可上傳圖片、輸入卡片名稱、選擇系列、選擇分類、設定稀有度、設定卡片編號，系統自動套版並預覽。

卡片建議尺寸：直式比例 3:4，建議輸出 900 × 1200 px，圖片需壓縮避免免費空間不足。

## 12.4 卡包管理與庫存制

卡包為可抽卡池。每個卡包可設定卡包名稱、描述、包含卡片、每張卡庫存、抽中權重、是否啟用、啟用日期、結束日期。

孩子抽到卡後：孩子收納包新增該卡、該卡包內該卡庫存 -1、抽卡紀錄新增一筆。不可刪除卡片主檔，只減少卡包庫存。

## 12.5 收納包

收納包需顯示已收集卡片、未收集卡片、系列完成度、稀有卡、最近獲得卡片。未收集卡片可用灰色剪影呈現。

# 13｜防膩與長期新鮮感機制

核心原則：學習邏輯固定進步，獎勵內容持續更新。

家長可持續新增新卡片、新系列、新分類、新卡包、新活動、新限定卡，不需修改程式碼。

支援主題週、限定卡、集滿系列獎勵與小孩端新鮮感提示。

小孩端提示範例：

1. 今天有新卡登場！
2. 這週是小車週！
3. 完成後可以抽狗狗卡包！
4. 還差 2 張就集滿小車系列！
5. 今天有神秘卡可以拿！

# 14｜抽卡條件設定

## 14.1 基本抽卡

1. 完成今日任務可抽 1 張
2. 完成英文 5 題可抽 1 張
3. 完成注音 5 題可抽 1 張
4. 今日完成率 100% 可抽 1 張

## 14.2 加碼抽卡

1. 弱點題答對 3 題加抽
2. 今日正確率達 90% 加抽
3. 新掌握 3 個項目加抽
4. 找到 3 個同符號記憶詞加抽

## 14.3 連續天數獎勵

1. 連續 3 天完成：加抽 1 張
2. 連續 7 天完成：抽稀有卡包
3. 連續 14 天完成：抽限定卡包

## 14.4 學習成果獎勵

完成注音聲母第一階段、英文 A 至 F 全部掌握、某系列熟練度平均達 4、某弱點項目成功解除弱點後，可獲得指定卡包或加抽。

建立 generated_questions、daily_learning_plan、自動產生每日任務、實作認識題、選擇題、聽音題、描寫題、practice_records、practice_attempts。

## Phase 4｜學習進度與弱點複習

建立 child_learning_progress，完成答題後更新熟練度，判斷弱點，設定複習間隔，後台顯示學習進度與弱點清單。

## Phase 5｜卡片與抽卡系統

建立 card_series、card_categories、cards、card_templates、reward_packs、reward_pack_items，後台上傳圖片，前端 Canvas 套版，小孩端抽卡動畫，卡片進入收納包，卡包庫存減少。

## Phase 6｜防膩與活動機制

建立 events、主題週、限定卡、活動卡包，小孩端顯示新卡提示與系列進度，支援集滿系列獎勵。

# 18｜成功指標

使用指標：孩子是否願意每天打開、每次練習是否能完成、是否連續使用 3 天、7 天、14 天、是否因為新卡而主動想練習、是否降低家長陪練壓力。

學習指標：注音與英文字母熟練度提升、弱點項目數量下降、正確率提升、容易忘的項目能透過複習改善、描寫練習完成度提升。

留存指標：新卡上架後是否提高使用意願、主題週是否增加完成率、收納包完成度是否驅動孩子回來練習、連續天數獎勵是否有效。

# 19｜產品核心流程總結

1. 家長建立學習項目。
2. 家長設定多個記憶詞。
3. 系統根據題型模板自動生成題目。
4. 系統每日產生新題、複習題、弱點題。
5. 孩子在手機上完成練習。
6. 系統記錄每一題作答。
7. 系統更新熟練度與弱點。
8. 完成條件後觸發抽卡。
9. 孩子獲得卡片。
10. 卡片進入收納包。
11. 卡包庫存同步減少。
12. 家長持續新增卡片、系列、卡包與活動。
13. 孩子因新卡與收集目標持續回來練習。

---

# 20｜v1.0 結論

本產品 v1.0 的核心不是打造大型兒童教育平台，而是完成一套家庭可控、手機可用、零額外月費、可持續更新內容的英文與注音練習系統。

最重要的產品邏輯是：小孩端極簡、家長端完整、題目自動生成、弱點自動複習、卡片持續更新、完成練習才有收藏獎勵、孩子每天為了新卡回來但過程中完成學習。

第一版應優先完成可用閉環：

建立題庫 → 自動出題 → 小孩練習 → 記錄進度 → 判斷弱點 → 完成抽卡 → 進入收納包 → 家長新增新卡。
