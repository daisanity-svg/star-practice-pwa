# Gameplay Blueprint — Chapter 1

> 本文件為第一章唯一的遊戲設計依據。凡舊有事件鏈、任務描述與本文件矛盾時，以本章為準。

## 核心循環（Main Loop）

```
冒險地圖（選擇節點）
    │
    ▼
練習 / Boss 戰鬥（完成事件）
    │
    ▼
回饋（星星、經驗、卡片）
    │
    ▼
返回地圖（下一步提示）
```

## 第一章任務鏈（唯一依據）

| 步驟 | 頁面 | 目標 | 完成提示 |
|------|------|------|----------|
| 1 | 首頁（/） | 認識今日冒險 | 「開始冒險」按鈕，導向冒險地圖 |
| 2 | 冒險地圖（/adventure） | 選擇當前節點 | 當前節點顯示「前往第 N 關」或「挑戰 Boss」 |
| 3 | 練習（/practice） | 完成今日題組 | 完成後自動返回地圖，節點標記完成 |
| 4 | Boss（/boss） | 打敗 Boss | 战斗结束后導向獎勵頁 |
| 5 | 獎勵（/reward） | 開啟卡包 | 翻牌後返回地圖或收納包 |
| 6 | 收納包（/collection） | 查看收集 | 可返回地圖繼續冒險 |

## 事件完成後的下一步提示規則

- **任何節點完成後**：頁面必須提供明確的下一步 CTA。
  - 普通節點完成後：顯示「返回地圖」或自動跳轉冒險地圖。
  - Boss 完成後：顯示「前往獎勵頁」或自動跳轉獎勵頁。
  - 獎勵開啟後：顯示「繼續冒險」返回地圖，或「查看收藏」進入收納包。
- **禁止事項**：事件完成後停留在空白頁面、沒有 CTA、或需要兒童自行猜測下一步。

## 功能狀態對照

### 保留（Retained）
- 冒險地圖 10 節點 + 3 Boss 節點
- 每日練習題組（注音 + 英文）
- Boss 戰鬥（HP/能量/3 題問答）
- 卡包翻牌與收集
- 家長後台（登入、摘要、卡片管理）
- Pet 成長系統
- Reward Draw Panel（今日獎勵）

### 暫停（Paused）
- 語言村翻卡 dead-end 流程（尚未實作，不進入第一章）
- 數學森林獨立關卡（目前僅於 feature/level-gameplay-math-language 分支存在，未合併）
- 翻卡遊戲無故事連線機制（見 Phase 8 Activity Packs 規劃，但第一章不啟用）

### 改造（Transformed）
- 舊版 card frames → V5.1 簡化卡面設計
- 家長後台 → 純文字摘要卡 + PIN 解鎖
- CompanionBar → 全站置頂導航列

## 第一章禁止事項

- 禁止新增與主線無關的小遊戲。
- 禁止兒童在第一章中直接跳入無引導的獨立功能頁。
- 禁止事件完成後無下一步提示。
