# UI Polish v1｜藍色兒童 App 美編方向

本輪 UI 美編以「藍色、柔和、兒童學習 App、手機優先」為核心。

## 已處理方向

1. 全域設計系統改為藍色主題。
2. 小孩端使用固定手機容器，降低左右溢出機率。
3. TopBar、BottomNav 改為柔和藍色兒童 App 風格。
4. 練習頁改為一題一頁：進度、題目主卡、選項、回饋、下一題。
5. 收納包頁改為圖鑑式卡片，不再使用表格線。
6. 獎勵頁改為抽卡感：卡包、恭喜、新卡、卡片展示。
7. 減少黑框，改用淡藍邊框、柔和陰影、大圓角。

## 待測重點

1. 手機 Safari 是否仍有左右溢出。
2. 練習選項是否可正常點擊。
3. 底部導覽是否遮住主要按鈕。
4. 收納包卡片是否有圖鑑感。
5. 獎勵頁卡片大小是否適中。

## 設計原則

- 小孩端：大字、大圖、大按鈕、少文字。
- 家長端：後續需分離成 Admin Layout，不再使用小孩端樣式。
- 主題色：藍色。
- 輔助色：黃色、薄荷綠、奶油白。
